# Misalignment Sensitivity and Critical Dimension Error in Optical Inspection Systems

## Goal
Small perturbations of elements in an infinity-corrected microscope system degrade imaging performance and can introduce bias in critical dimension (CD) measurements, leading to incorrect metrology results. This is particularly detrimental in precision inspection systems.
